# KCE Chatbot

A professional Flask + HTML/CSS/JavaScript chatbot interface for Kings College of Engineering.

## Project structure

KCE_Chatbot/
├── app.py
├── requirements.txt
├── README.md
├── templates/
│   └── index.html
└── static/
    ├── style.css
    ├── script.js
    └── kce-logo.png

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   pip install -r requirements.txt
4. Start:
   python app.py
5. Open the address shown in the terminal, normally:
   http://127.0.0.1:5000

The chatbot uses a local knowledge base in app.py, so it does not need an API key.

The KCE information was prepared using the official KCE website:
https://www.kingsengg.edu.in/
